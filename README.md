# 🛒 Flutter E-Commerce App with Node.js & MongoDB Backend

A complete e-commerce solution built using Flutter for the frontend and Node.js with MongoDB for the backend. This project demonstrates authentication, product management, secure API integration, and smooth cross-platform UI with backend connectivity.

---

## 🚀 Features

- User Authentication (Signup/Login with verification)
- Product Listing from MongoDB
- Image Upload Support
- JWT-based Secure API Communication
- Flutter Frontend + Node.js API Backend
- MongoDB Cloud Integration
